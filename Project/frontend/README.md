# Frontend

Frontend application — scaffold your preferred framework here.

## Getting Started

### Vite + React (TypeScript)

```bash
cd Project/frontend
npm create vite@latest . -- --template react-ts
npm install
npm run dev
```

Dev server starts at **http://localhost:5173**

### Next.js

```bash
cd Project/frontend
npx create-next-app@latest .
npm run dev
```

Dev server starts at **http://localhost:3000**

### Vue + Vite

```bash
cd Project/frontend
npm create vite@latest . -- --template vue-ts
npm install
npm run dev
```

## Backend API

The backend runs at `http://localhost:8000`. Configure your frontend to proxy or call that base URL.
